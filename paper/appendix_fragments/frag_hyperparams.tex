\section{Training hyperparameters}
\label{app:hyperparams}

This appendix records the exact settings behind every training run. Defaults live
in \texttt{config.py}; the few deviations (paper-matched SFT, control runs, the
cross-family judge) are noted inline. All runs use LoRA with the Tinker
importance-sampling loss and Adam.

We apply \emph{no} KL penalty to the policy: there is no KL coefficient for any RL
run. A \texttt{kl\_beta} argument was plumbed through the v2 trainer but never
implemented, so all runs are effectively $\beta=0$ (the Set~B output directories are
honestly labeled \texttt{beta0/}). The \texttt{kl\_coef} that does appear in the code
belongs to on-policy distillation (Table~\ref{tab:opd-hp}), not RL.

The Tinker framework-default SFT learning rate ($4.7\times10^{-4}$ for the 235B model)
silently over-optimizes the student and \emph{suppresses} the high-baseline animals
below baseline; we therefore report matched-LR ($10^{-4}$) numbers instead. The lesson
parallels the RL over-optimization caveat in the on-policy-distillation discussion
(\S\ref{sec:opd}).

\textbf{LoRA rank.} Rank 32 everywhere, with one exception: the 8B paper-match SFT
and the SFT/OPD control runs (\texttt{launchers/paper\_match.py},
\texttt{launchers/control.py}) use rank 8 to match the external subliminal-learning
reference setup.

\textbf{Animal sets.} Three sets are used across experiments:
\begin{itemize}[leftmargin=1.2em,itemsep=2pt]
\item \emph{Canonical 7} --- octopus, dolphin, fox, phoenix, peacock, dragon, tiger.
  Used for the main v2 RL sweep, the cross-model and Llama-judge RL, the naturalistic-probe
  RL, and the 8B/235B SFT$+$OPD scale comparison (\texttt{launchers/rl\_sweep\_v2.py}).
\item \emph{13-animal probe screen} --- dolphin, wolf, octopus, elephant, dragon, lion,
  tiger, dog, fox, peacock, cheetah, phoenix, panda. Used by the pre-RL signal-check /
  judge-probe screen (\texttt{probes/animal\_screen.py},
  \texttt{probes/run\_signal\_sweep.sh}).
\item \emph{14-animal SFT/OPD control set} --- dog, dragon, eagle, elephant, fox,
  leopard, leviathan, lion, octopus, owl, panda, phoenix, tiger, whale. Used by the
  unbiased-teacher SFT/OPD controls, which evaluate every animal
  (\texttt{launchers/control.py}).
\end{itemize}

\textbf{Seeds.} Per-experiment seed assignments:
\begin{itemize}[leftmargin=1.2em,itemsep=2pt]
\item Main v2 RL sweep: seeds $1$--$5$.
\item Extended RL runs: seeds $6$--$15$ (\texttt{launchers/rl\_multi\_v2.py}).
\item Cross-model, Llama-judge, filtered, and naturalistic RL: seeds $1,2$.
\item Same-recipe SFT/OPD (scale comparison): seed $1$.
\item External paper-match SFT/OPD: seed $42$.
\end{itemize}
